# Owner app Sinhala glossary

These terms are fixed. The web (`src/i18n/owner/si/`) and Flutter (`apps/mobile/lib/l10n/app_si.arb`) use the same ones, so an owner sees one word for one thing everywhere.

**This list needs a native-speaker review before launch.** To change a term, change it here and search-replace it in both places.

## Style
- Write plain, spoken Sinhala as used in Sri Lankan business and banking apps, not literary Sinhala. Address the owner politely without "ඔබ" in every sentence.
- Buttons are short verbs in the polite imperative: සුරකින්න (save), එක් කරන්න (add), යවන්න (send).
- Keep these in Latin script:
  - brand and channel names: Booking.com, Airbnb, Agoda, Vrbo, PayHere, PayPal, LankaQR, Wise, WhatsApp, Google;
  - technical identifiers: iCal, SLTDA, OTP, PDF, Excel, URL, ID;
  - currency codes and booking references: LKR, USD, SD-XXXX.
- Use Western digits (0–9). Write amounts with the currency code or symbol, unchanged.
- Placeholders (`{name}`, `{n}`, `{amount}`) stay exactly as in English, but move to where Sinhala word order needs them.
- Counts: Sinhala usually puts the number after the noun ("රාත්‍රී 3", "අමුත්තන් 2"). `_one` and `_other` may be identical.
